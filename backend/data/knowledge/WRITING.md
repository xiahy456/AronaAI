# RAG 知识语料书写规范

面向阿洛娜（Blue Archive）世界观知识库。源文件放在 `corpus/`，经 `scripts/ingest_knowledge.py` 写入向量库后供检索注入。

## 文件组织

- 一个主题一个 Markdown 文件，例如 `arona.md`、`shittim_chest.md`、`kivotos.md`
- 使用 `#` 作为文件总标题（可选，不参与切块）
- 使用 `##` 二级标题切分知识点：**每个 `##` + 其后正文 = 一条可检索知识**

## 切块写法

```markdown
# 主题名

## 短标题
一段自包含的中文陈述，80–300 字为宜。可在正文中写出常用别名。
```

入库时嵌入文本为：`【{二级标题}】\n{正文}`。

## 规则

1. **一块一件事**：身份、地点、术语分开写，不要混成长文。
2. **自包含**：单看这一块就能懂；少用「如上所述」「她」等悬空指代，首次出现写全名。
3. **长度**：正文约 80–300 汉字；过短难召回，过长噪声多且挤占 prompt。
4. **别名写入正文**：如「老师（Sensei）」「什亭之匣（Shittim Chest）」。
5. **与 system prompt 去重**：人设口吻已在配置的 `system_prompt` 中，知识库只写设定事实，不重复语气说明。
6. **稳定标题**：改文可以，尽量少改 `##` 标题（标题参与稳定 id）；必须改标题时请 `--rebuild` 全量重建。
7. **勿写入用户隐私**：用户生日、偏好等属于 `memory`，不要写进世界观语料。

## 推荐主题优先级

高频短设定优先：阿洛娜身份、什亭之匣、老师、基沃托斯、联邦学生会 / 沙勒等。

长剧情、活动复盘可后置，或拆成多块并控制长度。

## 更新流程

1. 编辑 `corpus/*.md`
2. 在 `backend/` 下执行：`python scripts/ingest_knowledge.py`（大幅结构调整用 `--rebuild`）
3. 可选：`python scripts/test_knowledge_rag.py` 验证召回
4. 配置中 `knowledge.enabled: true` 后重启后端
