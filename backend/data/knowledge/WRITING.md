# RAG 知识语料书写规范

面向阿洛娜（Blue Archive）世界观知识库。源文件放在 `corpus/`，经 `scripts/ingest_knowledge.py` 写入向量库后供检索注入。

检索会丢掉「阿洛娜 / 老师 / 我 / 你」等停用名，**不能靠角色名把知识块区分开**。一块只回答一类问题；老师会问的词要写进正文。

## 文件组织

- 一个主题一个 Markdown 文件，例如 `arona.md`、`shittim_chest.md`、`kivotos.md`
- 使用 `#` 作为文件总标题（可选，不参与切块）
- 使用 `##` 二级标题切分知识点：**每个 `##` + 其后正文 = 一条可检索知识**

## 切块写法

```markdown
# 主题名

## 短标题
一段自包含的中文陈述，80–300 字为宜。首句用主题词开头，并写出常用别名与问法。
```

入库时嵌入文本为：`【{二级标题}】\n{正文}`。

## 规则

1. **一块一件事**：身份、职责、服装、外貌、光环、地点、组织、器物、关系分开写。禁止在 A 块里定义 B（例如「与老师的关系」不要写什亭之匣是什么，也不要展开联邦学生会或基沃托斯概况）。
2. **自包含**：单看这一块就能懂；少用「如上所述」「她」等悬空指代，首次出现写全名。
3. **长度**：正文约 80–300 汉字；过短难召回，过长噪声多且挤占 prompt。
4. **别名与问法写入正文**：老师会说的词必须出现。例如身份写「谁 / 身份 / 操作系统管理员」；职责写「职责 / 工作 / 负责」；服装写「衣服 / 穿着 / 发带 / 裙子 / 伞」；光环写「光环 / 颜色 / 形状」。英文或日文别名放在括号里。
5. **主题词起句**：不要用「阿洛娜有……」开头。例如服装用「服装与穿着是……」，光环用「光环一般是蓝色圆环……」。
6. **与 system prompt 去重**：人设口吻已在配置的 `local_system_prompt` 中，知识库只写设定事实，不重复语气说明。
7. **稳定标题**：改文可以，尽量少改 `##` 标题（标题参与稳定 id）；必须改标题时请 `--rebuild` 全量重建。
8. **勿写入用户隐私**：用户生日、偏好等属于 `memory`，不要写进世界观语料。

## 推荐主题优先级

高频短设定优先：阿洛娜身份、什亭之匣、老师、基沃托斯、联邦学生会 / 沙勒等。

长剧情、活动复盘可后置，或拆成多块并控制长度。

## 更新流程

1. 编辑 `corpus/*.md`
2. 在 `backend/` 下执行：`python scripts/ingest_knowledge.py`（大幅结构调整用 `--rebuild`）
3. 可选：`python scripts/test_knowledge_rag.py` 与 `python scripts/eval_knowledge_rag.py` 验证召回
4. 配置中 `knowledge.enabled: true` 后重启后端
